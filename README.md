# SC Records – Edit Artist

Превью React-прототипа экрана Edit Artist, закрытое паролем.

Страница зашифрована целиком (AES-256-GCM, ключ из пароля через PBKDF2):
без пароля в исходном коде нет ни разметки, ни стилей, ни структуры.
Пароль передаётся отдельно, в репозитории он не хранится.

Исходники – в приватном репозитории `sc-edit-artist`.
